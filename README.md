# Du Life API

Backend de Du Life - Asistente Personal con IA por WhatsApp.

## Stack
- Node.js (serverless)
- Vercel (hosting)
- Supabase (PostgreSQL + pgvector)
- Claude API (razonamiento)
- OpenAI Embeddings (búsqueda semántica)
- WhatsApp Cloud API (Meta)

## Setup
1. `npm install`
2. Configurar `.env.local` con las credenciales
3. `vercel dev` para correr local
4. `vercel deploy` para subir a producción
